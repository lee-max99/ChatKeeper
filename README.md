# ChatKeeper · v0.6.2

通过页面提问目录定位问答，将当前 ChatGPT 对话保存为 **Markdown（.md）** 或带目录、搜索的 **离线 HTML（.html）**。适用于 Chrome / Edge；转换在浏览器本地完成，无需 OpenAI API Key。

## 安装与更新

下载：[ChatKeeper v0.6.2 安装包](https://github.com/lee-max99/ChatKeeper/releases/download/v0.6.2/ChatKeeper-0.6.2.zip) · [所有发布版本](https://github.com/lee-max99/ChatKeeper/releases)

下载后解压，按以下步骤安装。

1. Chrome 打开 `chrome://extensions`；Edge 打开 `edge://extensions`。
2. 开启开发者模式，选择“加载已解压的扩展程序”。
3. 选择解压后包含 `manifest.json` 的目录。开发者构建后选择项目中的 `dist` 文件夹。
4. 已安装旧版时，在扩展管理页点击刷新，**再刷新 ChatGPT 页面**。

请保留加载目录，不要移动或删除。本版本未发布到商店。

## 使用

1. 登录 `https://chatgpt.com`，打开一条已保存的对话，等待回答结束。若页面已结束，但保存记录仍带未完成状态，插件会导出当前保存内容并在文件里说明；部分回答可能尚未完整保存。
2. 点击页面右侧的小按钮打开提问目录；点击目录项，页面跳到对应问答，当前阅读项以淡紫色标记。
3. 在浮窗底部选择 Markdown / HTML，点击“下载”。也可以通过浏览器工具栏的 ChatKeeper 图标打开导出表单并修改文件标题。最终下载结果以浏览器下载列表为准。

需要部分导出时，点击目录旁的“选择”。插件会读取当前会话的完整保存目录，每个勾选项代表一个提问及其后续回答，可选择不连续的问答，也可全选或清空；未加载的历史提问同样可以选择。选择格式后点击“导出所选（数量）”，只保存勾选的问答，按原顺序排列，HTML 的目录和搜索也仅包含所选内容。选择模式中点击行文字也会勾选；点击“完成”退出后恢复目录跳转和完整下载。选择仅留在页面内存中，退出选择、切换会话或刷新页面会清空。若所选提问在读取时被编辑或移除，会提示重新选择，不自动改为整段导出。

读取过程不会滚动聊天页面。插件根据当前网址请求该条会话的完整保存记录，不受页面只显示少量消息的限制。页面消息 ID 仅作为选择回答版本的辅助信息：能唯一对应时使用页面选中的版本；无法识别或无法唯一对应时，使用该会话保存的当前版本。始终只导出一条消息路径，不合并其他回答版本或其他会话。读取期间请保留原页面；可取消操作。

页面浮窗以提问目录为主，底部仅保留格式选择和下载按钮。列表保留重复提问，长提问显示两行摘要，可悬停查看全文。新提问、编辑后的文字和页面补载内容自动更新；切换会话时保持展开并更新标题及目录，加载期间不显示旧提问。优先显示页面已加载的提问；展开后若一个提问也无法识别，会自动读取当前会话保存记录补齐目录，每个网址初次自动尝试一次，失败后可点击“读取目录”重试。

回退补齐或进入选择模式后，以当前会话的完整保存目录为基础，部分页面恢复识别不会删除历史项。聊天内容变化后延时更新记录，回答生成期间等待结束；读取期间再次变化也会继续更新。保存记录尚未变化时最多额外补读一次，不持续轮询接口。切换消息路径时使用新记录替换目录，不积累旧路径；更新失败保留现有目录，点击下载会再次读取。自动目录读取中也可直接选择格式并点击下载，复用正在读取的记录。不会合并其他分支或主动滚动补载。未加载或无法明确定位的提问仍会列出，点击时提示暂时无法定位；这仅表示目录跳转未成功，不影响下载或选择导出。若是旧消息尚未加载，可在聊天页向上滚动加载对应消息后重试；已显示的多行提问也会使用清理后的正文匹配。重复文字无法区分时不猜测跳转目标。目录识别不影响下载完整记录。

点击聊天区域后目录继续显示。拖动顶部可调整位置，点击右上角减号可收起；位置和最近选择的导出格式会保留，每次重新打开或刷新页面默认显示小按钮。扩展弹窗的“页面目录”开关可以隐藏或恢复入口。

收起目录不会中断工具栏的导出。关闭浏览器工具栏弹窗不会中断数据读取；重新打开可查看状态，但需要再点击导出才能保存，此时会重新读取最新数据。刷新、关闭或导航会丢失页面内存中的结果；切换会话会取消旧记录的准备。

## HTML 阅读页

- 问题目录、回答小标题导航；手机使用抽屉目录。
- 全文搜索与关键词高亮，保留命中消息所属的问答上下文。
- `Ctrl / ⌘ K` 搜索，`Enter` 切换命中消息，`Esc` 清除。
- 用户气泡、回答正文、代码复制、表格、MathML 公式。
- 单文件离线阅读，不自动加载远程图片、字体或脚本。
- 打印时隐藏目录，打印全部已导出消息，不受搜索筛选影响。

## 支持与限制

- 导出当前分支，不是账号全部历史或所有替代回答。保存标题、来源、导出时间、角色与正文。
- Markdown 保留原始文本与代码缩进；HTML 在本地转换 Markdown，支持列表、表格、代码和公式。
- 图片、音频和附件保留名称或可用链接，不嵌入原文件。链接可能需要登录或失效。
- Canvas、特殊工具卡片等不能保证完整还原，无法识别的非文本内容会显示说明。
- 新建未保存、临时对话、分享页面和正在生成的回答不支持导出。
- 使用 ChatGPT 网页内部接口，**不是有兼容性承诺的公开 API**。接口、登录校验或工作区限制变化时可能无法使用；会显示错误，不自动滚动或输出残缺文件。
- 单次读取超时为 45 秒；单个导出文件上限为 1000 万字符。

若出现“扩展连接已失效”或 `Extension context invalidated`，通常是扩展更新或重新加载后，聊天标签页仍保留旧脚本。刷新 ChatGPT 页面，重新打开浮窗再下载；只刷新扩展管理页不能替换已打开页面内的旧脚本。

## 权限与隐私

完整说明见 [隐私说明](docs/privacy.md)。

申请 `activeTab`、`scripting`、`downloads` 和 `storage`；页面脚本自动运行的范围仅为 `https://chatgpt.com/*`，用于显示浮钮。不申请 Cookie 读取或全网站访问权限。升级时浏览器可能要求重新启用扩展的 ChatGPT 站点访问。

打开页面或收起的浮钮不会启动自动读取完整聊天记录。目录展开时，扩展读取已加载的提问文字和节点以便跳转；没有可识别提问时自动读取当前会话保存记录，也可手动点击“读取目录”。进入回退模式后，聊天内容变化会触发延时更新和最多一次保存滞后的补读；收起或隐藏期间不启动新的自动读取，已开始的读取可以完成。上述回退读取、自动更新、进入选择模式和点击下载/导出时，页面脚本通过当前登录会话读取 `chatgpt.com/api/auth/session`，临时使用返回的访问令牌请求同一站点的当前对话接口。**令牌不写入文件、日志、扩展存储或弹窗消息，不发送给第三方。** 对话和目录临时保存在页面脚本内存中，无遥测或上传服务。扩展本地存储仅用于目录浮钮开关、位置和导出格式。

HTML 清除可执行内容，并使用随机 nonce 的 CSP 仅允许运行插件自带的离线阅读脚本；不允许自动外部资源请求。
