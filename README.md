# ChatKeeper · v0.7.5

我写的一个 ChatGPT 浏览器插件，用来查找提问、保存对话。支持 Chrome / Edge，可以导出 Markdown 或带目录、搜索的离线 HTML，无需 API Key。

## 安装

[下载安装包](https://github.com/lee-max99/ChatKeeper/releases/download/v0.7.5/ChatKeeper-0.7.5.zip) · [所有版本](https://github.com/lee-max99/ChatKeeper/releases)

1. 下载并解压安装包。
2. 打开 `chrome://extensions` 或 `edge://extensions`，开启开发者模式。
3. 点击“加载已解压的扩展程序”，选择包含 `manifest.json` 的解压目录。

更新时替换原目录的文件，重新加载扩展，再刷新 ChatGPT 页面。请保留安装目录。目前尚未上架商店。

## 使用

打开已保存的 ChatGPT 对话，等待回答结束，点击页面右侧的小按钮。

- **提问目录**：点击跳转，定位状态显示在对应条目旁，找到后短暂高亮目标；历史提问尚未加载时会自动滚动加载。手动操作聊天页或按 Esc 可停止定位。
- **搜索**：筛选目录中的提问，不影响已经勾选的内容。
- **选择问答**：勾选问答，支持不连续选择；展开“按序号选取”可选择范围。右侧箭头可定位核对，保留勾选。
- **导出**：选择 Markdown / HTML，点击“导出全部”或“导出所选”；工具栏图标导出当前会话全部问答。

退出选择会保留当前会话的勾选，重新进入可继续选择；普通模式仍导出全部。点击“清空”、切换会话或刷新页面会清除选择。

导出不需要滚动聊天页。读取记录、保存图片、等待浏览器保存会分别显示状态。确认完成后显示“已保存”；部分图片缺失会显示数量。结果待确认时请先按 Ctrl+J 查看下载列表，再决定是否重试。扩展更新后若提示连接失效，刷新 ChatGPT 页面即可。

## 说明

导出的是当前会话的一条回答分支，不包含账号全部历史。点击下载时尝试读取聊天原图并嵌入文件：HTML 可离线显示并通过“保存图片”单独下载，Markdown 使用内嵌图片链接（阅读器需支持 data URL）。音频和其他附件保留名称或可用链接。图片读取失败会明确提示并保留聊天正文。保存记录仍带未完成标记时，导出文件会提醒内容可能尚未完整保存。

HTML 支持常见静态卡片、紧凑标签、流程布局和 SVG 示意图，可展开多行数组及索引循环。可识别的柱状图、折线图会保存为离线矢量图，下方可展开查看原始数据；手机上可在图表区域横向滑动。Markdown 保留图表数据表。

离线文件不运行交互组件。复杂或无法识别的内容会保留静态文字或数据，不能保证与原页面完全一致。

支持 PNG、JPEG、WebP、GIF 和 AVIF，单张图片上限 5 MB。图片过大或无法读取时保留说明，正文仍可保存。

插件依赖 ChatGPT 网页内部接口，网页变化可能影响使用。不支持临时对话、分享页面及尚未保存的对话。

对话处理在本地完成，不上传到第三方，也不保存登录令牌。扩展只记住浮窗位置、开关和导出格式。[隐私说明](docs/privacy.md)

第三方依赖许可见安装包中的 `THIRD_PARTY_NOTICES.txt`。
