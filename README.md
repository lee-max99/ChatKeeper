# ChatKeeper · v0.3.4

将当前 ChatGPT 对话保存为 **Markdown（.md）** 或带目录、搜索的 **离线 HTML（.html）**。适用于 Chrome / Edge；转换在浏览器本地完成，无需 OpenAI API Key。

## 安装与更新

下载：[ChatKeeper v0.3.4 安装包](https://github.com/lee-max99/ChatKeeper/releases/download/v0.3.4/ChatKeeper-0.3.4.zip) · [所有发布版本](https://github.com/lee-max99/ChatKeeper/releases)

下载后解压，按以下步骤安装。

1. Chrome 打开 `chrome://extensions`；Edge 打开 `edge://extensions`。
2. 开启开发者模式，选择“加载已解压的扩展程序”。
3. 选择解压后包含 `manifest.json` 的目录。开发者构建后选择项目中的 `dist` 文件夹。
4. 已安装旧版时，在扩展管理页点击刷新，**再刷新 ChatGPT 页面**。

请保留加载目录，不要移动或删除。本版本未发布到商店。

## 使用

1. 登录 `https://chatgpt.com`，打开一条已保存的对话，等待回答结束。
2. 打开 ChatKeeper，按需修改标题，选择 Markdown / HTML。
3. 点击“导出”，等待浏览器弹出保存窗口。最终下载结果以浏览器下载列表为准。

读取过程不会滚动聊天页面。插件根据当前网址请求该条会话的完整保存记录，不受页面只显示少量消息的限制。页面消息 ID 仅作为选择回答版本的辅助信息：能唯一对应时使用页面选中的版本；无法识别或无法唯一对应时，使用该会话保存的当前版本。始终只导出一条消息路径，不合并其他回答版本或其他会话。读取期间请保留原页面；可取消操作。

关闭弹窗不会中断已经开始的数据读取；重新打开可查看状态，但需要再点击导出才能保存，此时会重新读取最新数据。刷新、关闭或导航会丢失页面内存中的结果。

## HTML 阅读页

- 问题目录、回答小标题导航；手机使用抽屉目录。
- 全文搜索与关键词高亮，保留命中消息所属的问答上下文。
- `Ctrl / ⌘ K` 搜索，`Enter` 切换命中消息，`Esc` 清除。
- 用户气泡、回答正文、代码复制、表格、MathML 公式。
- 单文件离线阅读，不自动加载远程图片、字体或脚本。
- 打印时隐藏目录，打印全部已导出消息，不受搜索筛选影响。

## 支持与限制

- 导出当前分支，不是账号全部历史或所有替代回答。保存标题、来源、导出时间、角色与正文。
- Markdown 保留原始文本与代码缩进；HTML 在本地转换 Markdown，支持列表、表格、代码和公式。
- 图片、音频和附件保留名称或可用链接，不嵌入原文件。链接可能需要登录或失效。
- Canvas、特殊工具卡片等不能保证完整还原，无法识别的非文本内容会显示说明。
- 新建未保存、临时对话、分享页面和正在生成的回答不支持导出。
- 使用 ChatGPT 网页内部接口，**不是有兼容性承诺的公开 API**。接口、登录校验或工作区限制变化时可能无法使用；会显示错误，不自动滚动或输出残缺文件。
- 单次读取超时为 45 秒；单个导出文件上限为 1000 万字符。

## 权限与隐私

完整说明见 [隐私说明](docs/privacy.md)。

仅申请 `activeTab`、`scripting`、`downloads`，不申请 Cookie 读取或全网站持久访问权限。

点击导出后，页面脚本通过当前登录会话读取 `chatgpt.com/api/auth/session`，临时使用返回的访问令牌请求同一站点的当前对话接口。**令牌不写入文件、日志、扩展存储或弹窗消息，不发送给第三方。** 对话临时保存在页面脚本内存中，无遥测或上传服务。

HTML 清除可执行内容，并使用随机 nonce 的 CSP 仅允许运行插件自带的离线阅读脚本；不允许自动外部资源请求。

```powershell

npm run build
npx playwright install chromium
npm run test:e2e
```

浏览器测试使用独立临时 Chromium 配置、仿真 ChatGPT 页面和接口响应，通过真实扩展动作授权并执行真实下载。覆盖 1000 条消息且页面只显示 4 条、页面完全没有消息标识、标识无法对应时的 Markdown / HTML 导出，以及零滚动、弹窗重开、取消、登录/接口失败、生成保护、HTML 离线搜索和移动布局。**不等同于登录后的真实 ChatGPT 页面或 Edge 实测。**

测试产物在 `artifacts`。更改源码后重新构建，再刷新扩展和 ChatGPT 页面。同步软件生成的 `*.sync-conflict-*` 备份保留在本地，不提交到仓库，也不参与 TypeScript 构建。

第三方依赖许可见扩展内的 `THIRD_PARTY_NOTICES.txt`。
