# 已结束回答的生成状态误判

用户确认页面回答已停止变化，停止按钮已消失。原“回答还在生成，请结束后重试。”来自 normalizeConversation 对任意导出消息 status=in_progress/pending/streaming 的硬性拒绝，与 pageInfo 的“请等待结束后重试”不是同一处。

复现包括早期回答及最后回答的未完成标记，或历史用户消息 pending，后面已有已完成内容。4 项新增断言先因该错误失败。修复改为导出当前保存记录，并加入一次“保存记录中仍有未完成标记，已导出当前保存的内容；部分回答可能尚未完整保存。”说明；不推断或修改服务端状态，不合并其他路径。页面实际的生成信号仍在准备前、读取完成和下载前由现有 guards 检查。

93 项单元测试通过，类型检查及构建通过。新增浏览器场景模拟已结束页面与残留 in_progress/pending 标记，检查 Markdown / HTML 实际文件内容和说明，并继续检查活动停止按钮时不可导出。实际用户的服务端返回尚未直接检查，修复基于具体错误出处与可复现路径。

最终验证：13 个导出浏览器场景通过，报告无页面错误；ChatKeeper-0.6.2.zip 共 14 文件，均与最终构建 SHA-256 一致。
