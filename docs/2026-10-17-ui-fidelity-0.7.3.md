# Intelligent UI 布局与图表 · 0.7.3

用户提供三张左右对照截图：严重程度标签与正文错位，流程图显示数组循环源码，柱状图只剩数据表。按截图内容构造回归样例后，确认以下代码路径可复现问题：

- 横向布局把所有直接子项等分，标签因此占据半行；紧凑标签、图标和明确的 flex 参数现单独处理。
- 原模板解析不支持多行二维数组、循环索引及下标条件；现使用平衡边界和作用域展开，六步流程可显示完整节点与五个箭头。
- 原 Chart 转换只输出数据表；已知柱状图、折线图结构现根据原始数据生成静态 SVG，保留数据表供展开查看。

HTML 仍使用 ChatKeeper 的离线阅读样式，不复制 ChatGPT 完整样式表或运行组件代码。常见字号、颜色、间距和布局在本地映射；矢量图按数据绘制，没有把截图中的像素当作原始数据。Markdown 保持可读文字和数据表。

## 范围与限制

表达式仅允许数据字面量、当前循环绑定、已有自有属性/下标、有限算术、比较与条件，不允许函数调用、全局对象、原型链、赋值或自增自减。数组每层最多 256 项，模板嵌套最多 12 层，共享展开量上限 2,000,000 字符，另有表达式与工作量限制。检查发生在逐片段追加时；超限块降级，保留周围正文。代码示例不参与模板展开。

图表支持 `chartType: bar/line`、`xKey`、`series[].dataKey` 与记录数组 `data` 的已知结构，最多 8 组序列、256 行。零值、负值和缺失值分别保留；未知图表类型、堆叠图或无法确认的数值结构回退为数据表，不编造数值。说明与脚注保留，完整标签可通过悬停查看。窄屏在图表区域横向滑动，页面整体不横向溢出。

离线搜索跳过 SVG 内部文字，避免插入 HTML 高亮破坏矢量图；匹配到折叠的数据表时自动展开。没有增加权限或远程请求。
