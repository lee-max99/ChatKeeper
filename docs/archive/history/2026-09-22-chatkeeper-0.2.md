# ChatKeeper 0.2.0 改动与验证

> 历史开发记录：本文描述当时的设计或验证结果，可能与当前版本不同。当前行为以根目录 README 和源码为准。

日期：2026-09-22

## 本次范围

- 扩展名称统一为 ChatKeeper，版本 0.2.0，图标与弹窗采用紫色。
- 弹窗移除宣传标题和重复说明，保留标题、格式、自动补采、进度与导出。
- 自动补采由点击导出触发；任务保存在当前页面脚本内存中，弹窗关闭后继续，重开可读取进度与结果。
- 原 25 秒截断改为每次 5 分钟的可续采时限。超时保留消息和滚动检查点，提供继续采集或明确导出部分。
- 到边缘后观察消息集合、滚动高度与加载指示，至少稳定 4 秒；每步等待虚拟列表更新，并容忍短暂空窗。
- 离线 HTML 改为目录与搜索侧栏、用户气泡、回答正文、代码复制，适配手机和打印。
- HTML 使用随机 nonce 允许自有离线脚本；原对话内容继续净化，禁止自动远程资源加载。

## 验证

- 27 项单元测试通过，TypeScript 类型检查与生产构建通过。测试涵盖 2.6 秒延迟加载、采集超过 25 秒、超时续采、顺序与去重、弹窗断开后的状态、取消、格式转换和不安全内容。
- Chromium 153.0.8010.12：真实扩展动作授权、页面注入、Markdown / HTML 下载、离线阅读与搜索、手机导航、虚拟列表 26 条消息、弹窗关闭重开、滚动恢复、编辑检测、取消、生成保护和站点限制均通过。详细结果见 `artifacts/browser-report.json`。
- 已目视检查弹窗、桌面阅读页与手机阅读页截图。
- 用用户提供的 HTML 内容生成 `artifacts/ChatKeeper-preview.html`，仅用于阅读版式预览，不执行参考文件脚本。

## 独立审查

完成只读代码审查。发现快速修改搜索词后按 Enter 会保留旧结果的问题，已先复现失败测试，再修复查询更新与结果导航的顺序；对应回归测试通过。未发现其他需要阻止交付的问题。

## 使用与边界

更新后必须刷新扩展，并刷新已打开的 ChatGPT 页面。采集时可关闭弹窗，但不要操作、刷新或关闭原页面。关闭弹窗后采集结果会留在页面内存中，重新打开并点击导出。

当前仍是页面 DOM 采集，不能证明账号侧历史完整；尚未在登录后的真实 ChatGPT 页面或 Edge 上验证。图片和附件仅保存链接。特殊卡片与其他分支不保证获取。
