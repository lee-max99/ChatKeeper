# ChatKeeper 0.3.3 页面消息识别

> 历史开发记录：本文描述当时的设计或验证结果，可能与当前版本不同。当前行为以根目录 README 和源码为准。

用户确认页面问题和回答已显示，但导出提示没有可识别的消息。

代码中该提示发生在 CK_PREPARE 的页面消息 ID 检查，早于登录会话和完整对话读取。原识别规则要求 data-message-author-role 和 data-message-id 同属一个元素。

未取得用户实际 DOM；浏览器连接工具启动失败。不能以截图确认实际属性层级，也不能将本次修复声明为现场根因已验证。

新增父层/子层 ID 和显式 conversation-turn 容器内 ID 的识别，仍仅使用精确 ID 与保存路径校验。公共多消息容器、无关页面 ID、隐藏消息均不能作为选择依据。可见角色消息部分无法识别时直接拒绝，避免仅依据可识别的旧消息猜选后续回答。生成中优先保留生成保护。

新增 6 项回归测试；51 项单元测试通过。浏览器仿真增加混合层级与无角色属性消息的真实扩展下载场景。生产构建和浏览器仿真验证结果见 artifacts/browser-report.json。
