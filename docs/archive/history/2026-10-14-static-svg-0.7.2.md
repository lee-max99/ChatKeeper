# 静态 SVG 连接图 · 0.7.2

用户在 0.7.1 新导出的 HTML 中发现设备连接图变为文字及四条“交互内容无法完整离线还原”。已确认的代码缺口是：SVG 子节点与普通组件共用递归文字转换，path/rect/line 等节点没有正文，可能逐个产生回退提示；未知电脑图标也会被省略。

用户提供的是截图，没有实际导出 HTML 或保存记录，因此不能仅凭截图确认四条提示各自对应什么源标签。回归按截图的设备、协议和连接关系构造 SVG 样例，验证这条可复现路径。

修复将 SVG 树整体处理。HTML 保留常见静态几何形状、文字、颜色、虚线、本地箭头/图形引用及坐标尺寸；Markdown 保留文字说明。补上电脑图标。SVG 用受限标签和属性重新构建，不直接插入原始源码；内部引用重写为独立 ID，不保留远程资源、脚本、动画或 foreignObject。文字实体安全解码后写入文本节点，代码中的 SVG 示例保持原文。

不支持任意动态绘图程序，也不保证未知组件与原页面完全一致。无法读取原始组件数据的内容仍需回原对话查看。

回归覆盖连接图、箭头、独立纯形状 SVG、显式尺寸、本地 use/xlink 引用、文字实体、恶意 SVG 及代码保护；浏览器检查离线渲染，无远程请求，截图保存在 artifacts/connection-diagram-0.7.2.png。

176 项单元测试、类型检查及构建通过；20 个导出浏览器模拟场景通过。已查看离线连接图截图，设备框、虚线、本地箭头及电脑图标可见，正文无重复回退提示。测试使用构造保存记录，尚未读取用户实际失败 HTML。
