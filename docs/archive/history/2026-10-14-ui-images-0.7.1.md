# 卡片静态渲染与原图保存 · 0.7.1

本次基线是用户确认的 0.7.0 同步版本。两张截图分别显示指标卡片失去颜色/字号/边框，以及 each 模板和 columns/gap 参数泄漏为正文。

## 原因与处理

0.7 的通用转换将组件展开为 Markdown 文字，HTML 再从 Markdown 渲染；视觉属性已经丢失。数值 columns 被误当作结构化数据属性，布局参数直接输出。循环模板没有展开。此次保留独立 UI 源文本供 HTML 使用，由同一组件树生成受控 CSS 类的静态卡片，Markdown 继续输出可读正文。循环仅处理有限的静态数组和字面量条件，不使用 eval 或执行用户脚本；未知分支降级提示，不猜测结果。

截图可证实渲染缺口，但未提供原始失败 HTML / 保存记录。回归用例按截图中的数值和结构构造，不能宣称已逐像素复现用户实际页面或覆盖全部未公开组件。

## 原图

消息内收集结构化图片、图片引用、Markdown 图片和可识别 Image 组件。仅在点击下载后获取本次范围内的原图，完整目录和选取不请求图片。内部 file-service 标识读取当前会话的同站点文件下载地址，CDN/公共图片请求不携带访问令牌或登录凭据。已知 ChatGPT CDN 可通过背景脚本读取，权限限定为 oaiusercontent.com 子域；其他来源依赖站点允许跨域读取。

响应验证 MIME、文件签名及浏览器解码。单图不超过 5 MB，正文读取全程有超时和取消，整体图片预算按 HTML 重复写入的显示/下载数据及导出文件剩余空间计算。失败保留说明和可用来源链接，不把坏图报为保存成功。

HTML 使用 data URL 内嵌图片，并提供保存图片的 download 链接；文件离线不访问远程图片。Markdown 内嵌同一图片，部分 Markdown 阅读器可能不支持 data URL。音频、视频及其他附件仍为说明或链接。无公开链接、失效签名、权限限制、过大图片或未支持的动态组件仍需要查看原对话。
