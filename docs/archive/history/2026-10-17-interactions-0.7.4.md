# 目录与导出交互 · 0.7.4

本次实现用户确认的前五项交互优化：明确范围、保留选择、逐条定位反馈、分阶段保存反馈和按需展开范围控件。沿用现有浮窗及工具栏流程，不加入导出预览。

## 操作与状态

- 普通浮窗与工具栏显示“导出全部”，保存当前会话的一条完整消息路径；选择模式显示“导出所选 · N 组”，每组包含提问及其后续回答。
- 退出选择保留当前页面内的勾选，普通模式依然导出全部；再次进入后继续选择。清空、切换网址/会话和刷新页面清除选择，不写入扩展存储。同步新记录时，已编辑或移除的提问会取消旧选择；真正导出前仍核验所选快照。
- 选择模式的勾选和定位入口分别处理。加载、停止及无法定位的文字显示在对应目录项，找到目标后短暂高亮；沿用有限加载、Esc 和手动操作取消、旧网址防护。重绘目录后恢复同一提问上的按钮或勾选框焦点。
- “按序号选取”默认折叠，展开时可见完整目录序号；搜索不改变这些序号与已有勾选。展开立即重新计算浮窗位置，窄屏保留底部导出入口。

导出过程按实际阶段反馈读取记录、保存图片、生成文件和等待浏览器保存；只在需要保存图片时显示该阶段，不显示估算百分比。记录及图片读取可取消，进入浏览器保存阶段后通过浏览器下载列表处理。

| 可确认的结果 | 反馈 |
| --- | --- |
| 浏览器确认文件完成 | 已保存及实际文件名 |
| 文件完成但有图片缺失 | 已保存及缺失图片数量，文件内保留详情 |
| 下载请求可能丢回复、状态查询不可用或等待超时 | 保存结果待确认，先按 Ctrl+J 查看，不自动再建任务 |
| 明确创建失败、中断、取消、被阻止或文件移除 | 对应错误和可执行的处理方式 |
| 首次请求无接收方或扩展上下文失效 | 连接恢复/刷新提示 |

目录定位状态不会覆盖导出结果。辅助操作使用较低视觉权重，主导出按钮与选中状态保持突出。权限、网络数据用途及本地设置字段不变；隐私说明已同步选择保留规则。

## 验证

测试覆盖退出重进后的实际导出范围、非选择模式下的旧选择失效、清空与切换重置、定位条目反馈和重绘焦点、图片取消、保存阶段及真实下载状态。浏览器使用真实解压扩展与构造的 ChatGPT 响应，检查历史节点自动挂载后仍保留焦点及勾选、选择控件折叠、窄屏布局与实际 Markdown/HTML 文件内容。

类型检查及生产构建通过；21 个测试文件共 219 项单元测试通过；31 个浮窗场景和 21 个导出场景通过。独立代码复查发现的定位按钮重绘焦点及首次连接失败分类问题已修复并复查。桌面、选择与窄屏截图已查看。

不增加跨刷新或跨会话选择存储，也不自动重试结果未知的下载。浏览器构造场景不代表所有用户页面或浏览器版本的兼容性证明。
