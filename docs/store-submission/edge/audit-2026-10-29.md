## 提交前必做

1. 账号：个人 Microsoft 账号加入 Edge 开发者计划，并确认后台验证状态。填写真实联系地址、邮箱等，公共机构示例地址不应作为个人地址提交。公司账号按后台要求准备对应的真实公司/授权资料，不要将公司核验材料当成所有个人账号的统一要求。
2. 隐私：现有 docs/privacy.md 数据流较完整，但末尾合规承诺只引用 Chrome 政策，未明确面向 Edge。Edge 政策 1.5.2 要求隐私政策主要面向 Microsoft Edge；建议发布 Edge 专用版本或明确 Edge 适用范围、用户控制与反馈方式，再同步公开 URL。新政策若随包分发，更新最终包并重新核对。
3. 登录测试：审核依赖第三方 ChatGPT 账号。政策 1.3.1 要求测试凭据，或明确合理的无法提供说明。现有英文说明仅要求审核员用自有账号，建议补充为何不提供发布者私人账号，并写清免费测试路径、已保存对话条件、地区/网络限制和无 API Key/ChatKeeper 账号要求。解释是否被接受由审核方判断，不保证免提供测试访问。
4. 隐私后台：逐项填写 activeTab、scripting、downloads、storage、oaiusercontent 访问理由及 chatgpt.com 页面匹配用途；说明聊天正文、标题/网址、临时令牌、图片来源请求和本地设置。按后台具体定义填写 Website content / Authentication information 等类别，不以“不上传开发者”代替“不访问用户数据”。
5. 真实 Edge 验证：使用最终待提交包，在当前 Edge 和真实已登录 ChatGPT 上测目录、长会话、选择问答、MD/HTML、图片、取消保存与离线阅读。旧 artifacts/edge-*-report.json 标记 fixtureOnly:true，不能作为真实网站测试证明。
6. 商店后台：确认名称、简介、中文详情、分类、图标、公开/隐藏、市场和审核说明。当前 UI 是简体中文，先只声明支持的语言；不要直接粘贴旧版同时宣传其他浏览器的文案。

## 源码抽查结论与边界

manifest 使用 V3，权限范围与目录/导出功能有对应关系，未申请 cookies 或全站访问。会话令牌用于 ChatGPT 同源请求，图片公共读取省略凭据，后台图片读取限制来源、超时、体积及格式；下载状态只查询本扩展任务。本次检查的网络入口未见开发者遥测上传端点或远程脚本执行入口。导出使用 DOMPurify 清理；静态组件表达式有受限解析器，不是 eval/new Function。上述为本次针对性检查，不是完整安全审计，也不代表微软一定接受。
