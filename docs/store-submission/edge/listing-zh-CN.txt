名称：ChatKeeper

简短介绍（来自 manifest）：
通过提问目录定位当前 ChatGPT 对话，将完整记录保存为 Markdown 或离线 HTML。内容在本地处理。

详细介绍（以下正文可粘贴）：
把想留下来的 ChatGPT 对话，保存成自己的笔记。

ChatKeeper 为 ChatGPT 网页提供提问目录、问答定位和对话导出。界面为简体中文，无需 OpenAI API Key，也无需注册 ChatKeeper 账号。

【提问目录与选择】
打开页面右侧的小按钮，浏览和搜索当前会话的提问。点击提问定位对应内容；历史消息尚未加载时会尝试滚动加载，按 Esc 或手动操作可以停止。进入选择模式可勾选不连续的问答，也可按序号选择范围。

【Markdown 与离线 HTML】
导出当前会话全部问答或所选问答，保留文字、代码、表格及可支持的内容。HTML 提供目录、全文搜索、代码复制和打印，可用浏览器离线打开。点击下载时尝试内嵌聊天图片；图片无法读取时会提示，其他附件保留名称或可用链接。部分静态组件和图表可转换为文字、数据表或矢量图，复杂交互不能保证完整还原，离线文件不运行原交互组件。

【本地转换与数据使用】
对话转换在浏览器本地完成，没有开发者运营的聊天上传、遥测或广告服务。读取当前会话需要登录 ChatGPT 和联网；导出图片时可能请求图片来源站点。临时访问令牌不会发送给开发者，也不写入导出文件或扩展设置。扩展仅在本地记住浮窗开关、位置和格式偏好。

【使用方式与限制】
登录 chatgpt.com，打开已保存的对话，等待回答结束。打开页面提问目录或工具栏 ChatKeeper 图标，选择格式后导出。不支持临时对话、分享页面或尚未保存的对话；只导出当前会话的一条回答分支。扩展依赖 ChatGPT 网页内部接口，网站变化或账号限制可能影响使用。

ChatKeeper 是独立扩展，与 OpenAI 或 Microsoft 无隶属或赞助关系。
