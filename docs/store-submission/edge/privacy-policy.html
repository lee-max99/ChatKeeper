ChatKeeper 隐私说明（Microsoft Edge）

更新日期：2026-10-29。适用于 Microsoft Edge 上的 ChatKeeper v0.7.5。

ChatKeeper 提供当前页面的提问目录，并将用户主动选择的当前 ChatGPT 对话导出为 Markdown 或离线 HTML。无需 OpenAI API Key。

读取和使用的数据

页面脚本检查当前网址以跟随会话切换。提问目录展开时，读取页面标题、已加载的提问文字及对应节点；读取滚动位置以标记当前问答，点击目录项时滚动到用户选择的提问；若目标尚未加载，会在聊天区域有限滚动，触发 ChatGPT 自身加载并再次定位，最多尝试 45 秒，可由用户操作停止。该过程不自行读取其他会话或修改聊天记录。目录和导航期间的旧提问快照仅留在页面内存中。没有可识别提问时，会自动从 ChatGPT 服务读取当前会话保存记录以补齐目录，每个网址初次自动尝试一次，也可点击“读取目录”重试。补齐后，检查聊天正文、附件名称和消息标识的变化，并延时重新读取当前会话以更新目录；回答生成期间等待，保存滞后时最多额外补读一次，不持续轮询服务端。尚未读取完整保存目录的已识别目录不会自动请求完整聊天接口。进入选择模式也会读取完整保存目录，此后目录变化沿用上述更新机制。收起或关闭目录时不会定时采集提问列表，也不会启动新的自动回退或更新；已经开始的读取可继续完成。

进入选择模式时，读取当前会话的完整保存记录以显示所有可选提问；已有可用完整记录时复用。每项对应一个提问及其后续回答；所选消息 ID 和文字仅留在页面内存中，退出选择后在当前会话内保留，点击“清空”、切换会话或刷新页面会清除，不写入扩展存储。点击“导出所选”只将所选问答保存到文件，普通模式的“导出全部”保存当前会话完整路径。

准备导出或目录回退时，读取可用的消息标识和回答生成状态。用户点击浮窗“下载”、工具栏“导出”，进入选择模式，或发生上述目录回退读取及自动更新时，扩展从 ChatGPT 服务读取完整消息内容。仅使用当前网址对应会话的一条消息路径，不合并其他分支。目录识别情况不会阻拦导出。点击下载时可读取并内嵌图片；其他附件保留名称或链接。

导出时在本地将图片引用和交互组件转换为可读文字、名称、可用链接、数据表或静态矢量图，保留保存记录中已有的组件数值、说明与控件状态；未知组件尽量展开静态正文和数据，无法还原时显示原对话查看提示。转换不读取未保存的页面交互状态，也不执行组件脚本。静态模板仅支持有限的数据读取、算术、比较、条件和数组展开，不执行函数、全局访问或修改状态的语法，展开量受限；图表仅按已有数据在本地绘制。图片读取的网络请求见下文。

扩展通过用户当前登录的 ChatGPT 会话请求 https://chatgpt.com/api/auth/session，临时使用返回的访问令牌请求同一站点的当前对话接口。这些请求会联系 ChatGPT 服务；本地转换不表示整个读取过程无需网络。

访问令牌不会写入导出文件、日志、扩展存储或弹窗消息，不会发送给开发者或第三方服务。

存储和共享

扩展没有开发者运营的上传服务器、遥测或广告服务。对话读取结果临时保存在当前页面脚本内存中，刷新、关闭或导航离开该页面后丢失。

扩展使用浏览器本地存储记住页面浮钮的显示开关、拖动位置和导出格式。不会在该存储中保存对话内容、对话标题、来源网址或访问令牌。卸载扩展会移除这些扩展设置。

导出文件保存到用户选择的本地位置，包含对话内容、标题、来源网址和导出时间；导出时间由扩展生成。文件可能包含个人或敏感信息，由用户决定是否分享及何时删除。卸载扩展不会自动删除已经下载的文件。

点击下载时，扩展尝试读取当前导出范围内的图片并内嵌到文件；进入目录和选择模式不会下载图片。ChatGPT 内部图片标识通过同站点文件接口获取下载链接，访问令牌仅发送到 ChatGPT；公共图片及 CDN 读取不带该令牌或登录凭据。图片数据仅留在本次导出的内存和用户保存的文件中，不写入扩展设置。外部图片站点在读取时会收到获取该图片的网络请求。

离线 HTML 只加载内嵌图片，不自动加载远程图片、字体或脚本。用户主动打开文件中的外部链接时，相应网站按其自身规则处理请求。

权限用途

  • activeTab：用户主动操作扩展时访问当前标签页。
  • scripting：在当前 ChatGPT 页面执行读取和导出所需的脚本。
  • downloads：保存用户请求的导出文件，并查询本扩展创建的该次下载状态和文件名，以显示完成或中断结果；不查询其他扩展的下载记录。
  • storage：记住浮钮开关、位置和格式。
  • https://*.oaiusercontent.com/*：在用户下载时读取 ChatGPT 图像 CDN 的原图，避免网页跨域限制导致图片丢失。
  • https://chatgpt.com/* 页面脚本匹配：在 ChatGPT 页面自动显示提问目录浮钮，支持定位问答和切换会话时更新目录。

扩展不申请 Cookie 读取权限或全网站访问权限，自动页面脚本仅运行在 ChatGPT 网站。

问题反馈

请通过 ChatKeeper GitHub Issues 反馈问题。不要在公开反馈中上传访问令牌、Cookie、未经脱敏的聊天内容或其他个人信息。

用户数据的有限使用

ChatKeeper 在 Microsoft Edge 中的数据处理遵守 Microsoft Edge Add-ons 的用户数据与权限要求。对话内容、页面信息和临时访问令牌仅用于本说明中列出的当前会话目录、导航及导出功能，不用于广告、画像、出售或与功能无关的用途。扩展不会将这些数据上传给开发者或第三方；与 ChatGPT 服务的必要通信如上所述。开发者不会通过扩展接收或人工查看用户的对话。用户主动提交的反馈由用户自行决定内容，不代表扩展自动上传聊天记录。

ChatKeeper 是独立浏览器扩展，与 OpenAI 无隶属关系。ChatGPT 服务自身的数据处理以其隐私政策为准。

用户控制与联系

你可以关闭页面目录以停止新的目录扫描或自动读取，按 Esc 停止定位，取消正在准备的导出，或在 Edge 扩展管理页禁用/移除 ChatKeeper。已经开始的请求可能继续完成；关闭或刷新相应页面会移除页面内存中的临时数据。扩展没有开发者保存的聊天副本。你可自行访问、分享或删除本地导出文件；禁用或卸载扩展不会删除它们。隐私问题可通过上述 GitHub Issues 反馈，请不要在公开页面提交敏感内容。
