# ChatKeeper 商店文案（v0.6.4）

## 名称

ChatKeeper

## 简短介绍

通过提问目录定位当前 ChatGPT 对话，将完整记录保存为 Markdown 或离线 HTML。内容在本地处理。

Edge 的简短介绍来自安装包 manifest.description，与上述文字一致。

## 详细介绍（可直接粘贴）

把想留下来的 ChatGPT 对话，保存成自己的笔记。

ChatKeeper 是面向 ChatGPT 网页的浏览器扩展，提供提问目录、问答定位和聊天记录导出。支持 Chrome 与 Microsoft Edge，当前界面为简体中文。

【提问目录】
在聊天页面打开浮窗，查看提问列表，点击目录定位对应问答。目录会随当前对话更新；尚未加载的历史提问会尝试通过页面滚动加载后定位，也可以停止定位。

【完整导出或选择导出】
下载当前会话保存的整段记录，或勾选需要的问答后导出。读取保存记录不依赖页面已显示多少消息，只导出当前会话的一条消息路径，不合并其他会话或替代回答版本。不能唯一识别页面选中的回答版本时，使用该会话保存的当前版本。

【两种文件格式】
Markdown：保留文字和代码，方便继续整理笔记。
HTML：用浏览器打开即可离线阅读，提供问题目录、全文搜索、代码复制、表格与公式展示，也支持打印。无需另外安装阅读器。

【本地处理】
不需要 OpenAI API Key。转换在浏览器本地完成，没有开发者运营的聊天上传、遥测或广告服务。读取记录时需要当前 ChatGPT 登录状态及网络，会与 ChatGPT 服务通信；对话及临时访问令牌不会发送给开发者。

【使用方式】
登录 chatgpt.com，打开一条已保存且回答已结束的对话。打开页面右侧提问目录或浏览器工具栏的 ChatKeeper 图标，选择 Markdown / HTML 后下载。需要部分内容时，进入目录的选择模式，勾选问答并导出所选。

【使用前请了解】
支持已保存的 ChatGPT 对话，不支持临时对话、未保存的新对话或分享页面。完整导出以服务端保存的内容为准，尚未保存的回答可能不完整；附件仅保留名称或可用链接，不打包原文件。Canvas 和特殊工具卡片不能保证完整还原。使用 ChatGPT 网页内部接口，页面或接口更新、登录失效及工作区限制可能影响读取。单个导出文件上限为 1000 万字符。

ChatKeeper 是独立扩展，与 OpenAI 或 Microsoft 无隶属或赞助关系。
