# ChatGPT 本地导出插件设计

> 历史开发记录：本文描述当时的设计或验证结果，可能与当前版本不同。当前行为以根目录 README 和源码为准。

用户已确认：手动导出当前对话为 Markdown / HTML，并授权按此方案继续实现。

## 目标与范围
Chrome / Edge Manifest V3 扩展；中文弹窗；当前 chatgpt.com 对话的当前显示分支；本地处理，无服务器、API Key、账号令牌读取或遥测。输出对话标题、来源链接、导出时间、角色和正文。图片/附件以链接和说明保存，不承诺离线资源备份。

## 流程
点击扩展后校验来源网站，注入内容脚本并采集当前渲染消息。弹窗允许编辑标题，选择 Markdown / HTML，查看消息数与范围提示，启动可选长对话滚动补采，再下载。生成中禁止导出并提示重试。补采有时间上限、取消入口、去重和滚动位置恢复；页面导航或分支变化中止采集。始终声明 DOM 采集无法验证账号侧完整性。

## 模块
- `src/collector.ts`：DOM 适配、消息提取、生成状态和滚动补采。
- `src/content.ts`：隔离世界中的消息监听；重复注入幂等。
- `src/exporters.ts`：内容清理、Markdown 和独立 HTML 输出、文件名规范化。
- `src/popup.ts` / `popup.html` / `src/popup.css`：弹窗状态、采集、预览概要、下载交互。
- `src/background.ts`：下载 API 调用，避免弹窗关闭使下载处理丢失。
- `src/types.ts`：结构化对话接口。

## 输出约定
正文保留段落、列表、引用、代码、普通表格与合法链接。代码内反引号不会截断 fenced code。公式能读取 LaTeX 时以原式保存；HTML 使用静态公式样式或原式回退。清除脚本、事件、表单、操作按钮及危险 URL。HTML 不加载远程脚本/CSS/字体，图片转为链接与占位说明。外链不自动请求。正文中的代码文本原样转义保存。

## 权限
仅 activeTab、scripting、downloads。只允许 https://chatgpt.com；不申请全站永久访问权限、Cookie 或网络拦截权限。

## 完整性与错误
不把页面快照标成完整历史。自动补采滚动到两端并汇集实际观察到的节点，稳定 ID 去重且保留相同内容的不同消息；缺少稳定 ID 时使用节点身份，标注虚拟列表可能重复/不完整。不能识别正文时保留可见文字并提示格式退化；不能识别消息、导航中、生成中、下载失败均有中文反馈。用户可取消，超时给出已采集范围。

## 验证与交付
Vitest + jsdom 验证 DOM 提取/格式转换/错误边界；Playwright Chromium 用仿真 ChatGPT DOM 验证真实扩展加载与两种下载。仿真页面测试不等同登录后的真实 ChatGPT 兼容性验证。交付源代码、锁文件、可加载 dist、安装包 ZIP、中文 README、测试记录。
